# /estado

Delegá en la skill `my-flow:estado` con los mismos argumentos: invocá `/my-flow:estado $ARGUMENTS`.

Si el plugin no está instalado, como mínimo corré `make estado` y mostrá el bloque generado de `docs/etapas/ESTADO.md` sin editarlo.
